# Решение задач для стажировки в Bell Integrator

Данный репозиторий содержит решения четырёх тестовых задач, выполненных в рамках отбора на стажировку Java-разработчика в компанию **Bell Integrator**.

## 📁 Структура репозитория
- `src/main/java/test/ru/` — исходный код всех решений (каждая задача в отдельном `.java` файле)
- `.gitignore` — исключены служебные файлы IDE и сборки
- `pom.xml` — конфигурация Maven с необходимыми зависимостями
- `README.md` — описание проекта

## 🛠️ Технологии
- Java 17
- Maven
- Git

Файлы были скомпилированы на локале.
Код решений был проверен на корректное решение задач.
